# New experimental paradigms and tools for consumer research

This repository holds a [web version of the slides](howquez.github.io/new-tools-ACR/) for our session at ACR 2026 (Chicago, 26 September 2026). 
The session presents four tools that let consumer researchers run experiments in (more) realistic digital environments: 
Open Science Online Grocery, DICE, TestTube and a simulated online bookstore. 

The (slightly edited) slide deck that the page is based on is available on [Zenodo](https://doi.org/10.5281/zenodo.23154344), together with the original session proposal for ACR 2026. 

Please note that this page is a "vibe coded" version of the original PowerPoint deck. 
It was built with an AI assistant (Claude) from the slides. 
It was therefore not written by hand and may contain small differences from the original version. If the page and the deck disagree, the deck is the reference.
